v1 · HTTPS · 2026-11-03
传真投递接口

通过 HTTPS 发送传真

上传 PDF、图片或文本文件，接收后返回任务编号。可以查询任务的处理状态。

Base URL https://fax.verstappen.uk
目录 鉴权 发送传真 请求字段 文件限制 响应 查询状态 错误码 调用示例 重试与幂等

鉴权

每次请求都需要在报头中携带 Bearer 密钥。密钥由传真站管理员发放。

Authorization: Bearer sfx_xxxxxxxxxxxxxxxxxxxx

也可以使用兼容报头：

X-SimuFax-Key: sfx_xxxxxxxxxxxxxxxxxxxx
请妥善保管密钥。 不要把密钥放在 URL、公开仓库或日志中。密钥遗失或泄漏时，请联系管理员停用并更换。

sender、recipient、subject 等字段均为自由文本，密钥有效即可发送。

发送传真

POST /api/v1/fax

请求类型必须是 multipart/form-data。文件放在 file 字段中，元数据可以放在表单字段或报头中。

curl --fail-with-body \
  -X POST "https://fax.verstappen.uk/api/v1/fax" \
  -H "Authorization: Bearer $SIMUFAX_KEY" \
  -F "sender=财务室" \
  -F "recipient=传真站" \
  -F "subject=十一月对账单" \
  -F "file=@invoice.pdf"

接收成功返回 202 Accepted，并带有任务编号。返回成功只表示文件已被接收，处理状态请通过状态接口查询。

请求字段

表单字段

字段必需说明
file是要发送的文件。
sender否发件人名称，可以任意填写；缺省为“未知发件人”。
recipient否收件人，缺省使用站点默认值。
subject否主题，最多 200 个字符。
message否附言，最多 2000 个字符。
message_id否幂等编号，也可以通过报头传递。

可选报头

报头说明
X-SimuFax-Message-Id幂等编号。相同密钥和发件人重复提交时返回原任务。
X-SimuFax-Sha256文件 SHA-256，共 64 位十六进制字符。提供时会校验文件完整性。
X-SimuFax-Pages页数。提供时必须与实际页数一致。
X-SimuFax-Timestamp发送端时间，仅记录。
X-SimuFax-Client-IP发送端声明的 IP 地址，仅记录。

涉及中文的字段建议放在表单字段中，避免 HTTP 报头的字符集差异。

文件限制

接受以下文件类型：

  • PDF
  • PNG、JPEG
  • TIFF
  • UTF-8 或 GB18030 编码的纯文本

单文件大小上限和页数上限由站点配置决定。超过限制时返回 413 或 422。建议中文文档使用 PDF。

接口对请求频率有限制。超过限制时返回 429 Too Many Requests，并带有 Retry-After 响应头。

响应

HTTP/1.1 202 Accepted
Content-Type: application/json
{
  "ok": true,
  "id": "F20261103-A1B2C3D4E5",
  "status": "pending",
  "pages": 3,
  "checksum": "a1b2c3...",
  "duplicate": false,
  "received_at": "2026-11-03T11:30:00+00:00"
}

如果同一个 X-SimuFax-Message-Id 重复提交，会返回 200 和原任务，duplicate 为 true。

查询状态

GET /api/v1/fax/{id}

使用发送时同一把密钥：

curl -s \
  -H "Authorization: Bearer $SIMUFAX_KEY" \
  "https://fax.verstappen.uk/api/v1/fax/F20261103-A1B2C3D4E5"
pending已接收，等待处理
printing正在打印
printed打印完成
rejected已被站点拒绝
failed处理失败

错误码

HTTP含义
400请求参数或报头格式错误。
401缺少密钥或密钥无效。
404任务不存在，或密钥无权查询。
409幂等编号冲突。
413请求体过大。
415Content-Type 不是 multipart/form-data。
422文件类型、大小、页数或校验值不符合要求。
429请求过于频繁。请按 Retry-After 等待。
500服务处理失败。
503服务暂时不可用。

错误响应：

{
  "ok": false,
  "error": "SHA-256 校验失败，文件可能在传输中损坏",
  "code": "invalid_document"
}

健康检查：GET /api/v1/health，不需要鉴权。

调用示例

Linux / macOS

export SIMUFAX_KEY='sfx_...'
export FILE='/path/to/invoice.pdf'
HASH="$(sha256sum "$FILE" | awk '{print $1}')"

curl --fail-with-body \
  -X POST 'https://fax.verstappen.uk/api/v1/fax' \
  -H "Authorization: Bearer $SIMUFAX_KEY" \
  -H "X-SimuFax-Message-Id: $(date +%s)-$USER" \
  -H "X-SimuFax-Sha256: $HASH" \
  -F "sender=财务室" \
  -F "recipient=传真站" \
  -F "subject=十一月对账单" \
  -F "file=@$FILE"

macOS 可使用 shasum -a 256 "$FILE" 计算哈希。

Python

import hashlib
import requests

path = "invoice.pdf"
key = "sfx_..."

with open(path, "rb") as handle:
    files = {"file": (path, handle, "application/pdf")}
    data = {
        "sender": "财务室",
        "recipient": "传真站",
        "subject": "十一月对账单",
    }
    response = requests.post(
        "https://fax.verstappen.uk/api/v1/fax",
        headers={
            "Authorization": f"Bearer {key}",
            "X-SimuFax-Sha256": hashlib.sha256(open(path, "rb").read()).hexdigest(),
        },
        data=data,
        files=files,
        timeout=120,
    )

print(response.status_code)
print(response.json())

重试与幂等

建议每次发送使用唯一的 X-SimuFax-Message-Id。网络超时或连接中断时，可以用同一个编号重试，不会重复创建任务。

  • 202 或 200：不要重试。
  • 429：等待 Retry-After 后再试。
  • 500 或 503：可以使用相同编号稍后重试。
  • 4xx 参数错误：修正请求后再试。
